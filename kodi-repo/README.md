# Droid Buddy 3 Kodi Repository

This folder contains the Kodi repository metadata and packaged releases for:

- Droid Buddy 3 skin
- DB3 ROM Browser

Install `repository.droidbuddy3-1.0.0.zip` in Kodi, then open **Install from
repository → Droid Buddy 3 Repository** to install either add-on. Kodi will use
this repository for future updates.

Repository metadata and packages are served from the `master` branch through
`raw.githubusercontent.com`.
